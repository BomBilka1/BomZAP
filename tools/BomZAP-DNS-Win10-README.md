# BomZAP Secure DNS для Windows 10 x64

Утилита использует AdGuard dnsproxy v0.86.0 и Google DNS через HTTPS. Она проверяет локальный прокси до изменения настроек, затем меняет только IPv4 DNS выбранного адаптера на 127.0.0.1. Другие адаптеры и IPv6 не меняются. При включении компьютера прокси запускается через планировщик заданий Windows.

Распакуйте весь архив в одну папку, откройте PowerShell от администратора и выполните `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "ПОЛНЫЙ_ПУТЬ\BomZAP-DNS-Win10.ps1"`. Выберите интернет-подключение. Программа сохранит предыдущие IPv4 DNS в `%ProgramData%\BomZAP\SecureDNS\previous-dns.json` и проверит разрешение YouTube.

Чтобы отменить настройку, выполните ту же команду с `-Restore`. Если локальный прокси перестанет работать, DNS на выбранном адаптере может не работать до восстановления или перезапуска задачи `BomZAP Secure DNS`. Другие DNS-серверы, включая IPv6, могут по-прежнему использоваться Windows. Прокси не является VPN и не гарантирует работу YouTube; после настройки требуется проверить его с работающей стратегией BomZAP.

Исходный проект: https://github.com/AdguardTeam/dnsproxy . Лицензия прилагается. Бинарный файл проверяется по SHA-256 перед установкой.
