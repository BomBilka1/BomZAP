# Автообновление BomZAP

Запустите `service-enable-updates.bat` от администратора, чтобы включить проверку стабильных релизов BomZAP на GitHub при каждом входе в Windows. Скрипт также сразу проверит наличие обновления. Чтобы обновить уже установленную предварительную версию, поместите этот BAT в папку BomZAP, а `BomZAP-update.ps1` — в её папку `utils`, затем запустите BAT.

Обновления скачиваются только из `BomBilka1/BomZAP`, версия должна быть новее установленной, а SHA-256 архива должен совпадать с данными GitHub. Перед заменой изменённых файлов создаётся резервная копия. Служба в папке BomZAP временно останавливается и запускается снова, если она работала. При ошибке программа пытается восстановить предыдущие файлы и состояние службы; незавершённое обновление восстанавливается при следующем запуске проверки.

Пользовательские списки, режимы Game Filter/IPSet, списки целей и активные UDP-файки сохраняются. Персональный список доменов объединяется со списком из релиза. Если winws запущен вручную, обновление откладывается. Отключить проверку можно в планировщике заданий Windows, удалив задачу `BomZAP Auto Update`.

Если обновление не удалось восстановить автоматически, резервные файлы находятся в `%ProgramData%\BomZAP\update\backup`. Проверка не гарантирует работу Valorant или голоса Discord после обновления; проверьте их самостоятельно.
